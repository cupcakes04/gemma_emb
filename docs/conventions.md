# Conventions

The rules the engine enforces, and why. The evidence behind each "why" is in [model-facts.md](model-facts.md).

## Tasks and sides

| Task | Kind | Methods | Prefix the engine adds |
|---|---|---|---|
| `search` | asymmetric | `embed_queries` / `embed_documents` | `task: search result \| query: ` / `title: … \| text: ` |
| `question_answering` | asymmetric | same | `task: question answering \| query: ` / same |
| `fact_checking` | asymmetric | same | `task: fact checking \| query: ` / same |
| `code_retrieval` | asymmetric | same | `task: code retrieval \| query: ` / same |
| `classification` | symmetric | `embed` | `task: classification \| query: ` |
| `clustering` | symmetric | `embed` | `task: clustering \| query: ` |
| `similarity` | symmetric | `embed` | `task: sentence similarity \| query: ` |

- Using the wrong method for a task raises `TaskError`.
- The document prefix is `title: {title} | text: `, or `title: none | text: ` when the item has no title. Titles exist only on the document side; a title anywhere else raises `TaskError`.
- Prefix strings live in one place: `tasks.py`. You never type them; `eg.preview` shows them.

## Items

An `Item` is an ordered sequence of parts, embedded into **one** vector.

```python
eg.Item.text("...", title=None)
eg.Item.image(path_or_PIL)
eg.Item.video(path, include_audio=False, overflow="error")
eg.Item.audio(path)                       # or eg.Item.audio(array, sampling_rate=44_100)
eg.Item.of("caption", eg.Image(p), "more text", eg.Video(v), title="...")
```

- **Lists only.** The embed methods take a list. A bare `str` or `Item` raises `InputError`.
- **Strings are always text.** A plain `str` in the list is `Item.text(str)`; it is never sniffed for file paths or URLs. Media must be wrapped in `Image`, `Video` or `Audio`. A `Path` passed as a part raises `InputError`.
- **Order is kept.** Placeholders for media are generated by the engine. Text containing `<|image|>`, `<|video|>` or `<|audio|>` raises `InputError`.
- **The prefix is added only when the item has text or a title.** Media-only items get no prefix (model card; measured best).
- Empty text, or an item with no parts, raises `InputError`.

## Vectors

- `dim` is 768 (default), 512, 256 or 128. Every row is **L2-normalized after truncation**, in float32.
- Results are `Embeddings` objects carrying `vectors (n × dim, float32)`, `task`, `side`, `dim`, `model`, `revision` and per-item `token_counts`. They round-trip through `to_json()` / `from_json()`.
- `similarity`, `top_k` and `near_duplicates` refuse to compare embeddings with different `dim`, `task` or model revision (`IncompatibleEmbeddingsError`).
- Query vs document of the same task is the intended comparison. Document vs document and query vs query are allowed.

## Media

| | Rule | Default | Error |
|---|---|---|---|
| Image | path or PIL image; `image_tokens` soft tokens | 280 (≈266–276 used) | `MediaError` if the file is missing |
| Video | path; frames = floor(duration × `video_fps`) | 1 fps, ≤ 32 frames, 140 tokens/frame | `FrameLimitError` if frames > `video_max_frames`, unless `overflow="subsample"` |
| Video soundtrack | `include_audio=True` adds an audio part after the frames | off | `MediaError` if the file has no audio stream |
| Audio file | decoded by FFmpeg, mono 16 kHz | full length (no 30 s cut) | `MediaError` if not decodable |
| Audio array | `(samples,)` or `(channels, samples)` plus `sampling_rate`; downmixed and resampled | — | `InputError` without `sampling_rate` or with a wrong shape |

Budgets (`image_tokens`, `video_frame_tokens`, `video_fps`, `video_max_frames`) are **engine** settings, not per-call settings: vectors made with different budgets are different vectors.

## Context

- Each item may use at most `max_tokens` (8,192) tokens: text + special tokens + 25/s of audio + image and frame soft tokens.
- The check runs on the real processor output, before the model runs, and raises `ContextOverflowError` with a breakdown.
- `engine.count_tokens(items, task=..., side=...)` returns the same exact breakdown. It loads only the processor (no weights), and it reports items over the limit instead of raising.
- `eg.preview(item, task=..., side=...)` returns the exact text the model receives, with media as `<|image|>` / `<|video|>` / `<|audio|>` placeholders. It loads nothing.

## Model, dtype and lifecycle

- Weights come from the Hugging Face cache at a pinned revision, offline (`local_files_only=True`). If they are missing, `ModelNotFoundError` gives the `hf download` command.
- `dtype="auto"` means bf16 on GPUs that support it, otherwise fp32. **float16 is refused** (`ConfigError`) because it returns NaN on long inputs. A NaN or inf in any output raises `NumericalError`.
- `modalities` picks the towers: text 0.54 GB, +vision 0.89 GB, +audio 1.15 GB, all 1.50 GB. An item that needs an unloaded modality raises `ModalityNotLoadedError` before anything is decoded.
- The model loads on first use (or `engine.load()`). `engine.unload()` frees it; `with EmbeddingEngine(...) as engine:` unloads on exit.
- One engine can be shared between threads: preprocessing and the forward pass run under one lock.
- `import embeddinggemma_engine` does not import torch, transformers or sentence-transformers.

## Errors

| Error | When |
|---|---|
| `ConfigError` | bad `EngineConfig` (fp16, unknown modality, bad budget), no CUDA, wrong model type |
| `ModelNotFoundError` | weights not in the cache / directory |
| `TaskError` | unknown task, wrong method for the task, title outside documents |
| `InputError` | malformed item, bad audio array, bad `dim` / `k` / threshold |
| `MediaError` | missing or undecodable file, no audio stream |
| `ModalityNotLoadedError` | item needs a tower that wasn't loaded |
| `ContextOverflowError` | item over `max_tokens` |
| `FrameLimitError` | video would lose frames |
| `NumericalError` | NaN or inf from the model |
| `IncompatibleEmbeddingsError` | comparing different spaces |

All of them inherit from `EngineError`, and also from the matching builtin (`ValueError`, `OSError` or `RuntimeError`).
