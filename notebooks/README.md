# Notebooks: user guide

Read them in order. Each one is short, explains one idea at a time, and ends with the
mistakes you're most likely to make. Run them after installing the package (see the main README).

| # | Notebook | You'll learn |
|---|---|---|
| 01 | [Quickstart](01_quickstart.ipynb) | Embed a few documents and search them: the whole idea in five cells |
| 02 | [Tasks and prompts](02_tasks_and_prompts.ipynb) | **What the model actually reads.** Tasks, query vs document, titles, media. Uses `eg.preview` |
| 03 | [Search](03_search.ipynb) | Searching text, images, videos, audio and mixed collections; smaller vectors |
| 04 | [Labelling](04_labelling.ipynb) | Zero-shot labels with `eg.classify`, and how to spot unsure ones |
| 05 | [Duplicates and clustering](05_duplicates_and_clustering.ipynb) | `eg.near_duplicates`, picking a threshold, grouping |
| 06 | [Media settings](06_media_settings.ipynb) | Token costs, long videos, soundtracks, audio arrays, loading less |

Looking for the measurements behind the design? They're in [`../research`](../research/README.md).
